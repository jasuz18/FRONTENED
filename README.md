This project was developed as part of a hands-on web development workshop organized by our institution. The goal was to construct a responsive, aesthetic, and user-centric Static Authentication Page featuring seamless navigation between user login and registration interfaces.

Front-End Fundamentals: Applied core principles of structured markup (HTML5) and styling (CSS3) to design interactive form elements and user interfaces.

Responsive Layout Design: Leveraged modern layout modules such as Flexbox and CSS Grid to ensure complete cross-device compatibility and optimal viewing across desktop, tablet, and mobile displays.

Practical Workshop Application: Successfully translated theoretical concepts delivered during the college technical session into a functional, real-world web interface prototype.
